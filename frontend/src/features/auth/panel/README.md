# auth/panel

Panel protegido, solo accesible logueado. Agrupa las tres funciones del personal administrativo:

- Dashboard de estadísticas propio (búsquedas sin resultado, términos más buscados).
- Gestión (alta/baja/modificación) del contenido de los paneles de carga.
- Gestión (alta/baja/modificación) de los usuarios que pueden entrar a los paneles.
